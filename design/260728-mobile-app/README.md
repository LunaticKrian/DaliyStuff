# PixelPack · 移动端客户端 设计稿 v1.0

> 日期：2026-07-28
> 模块：移动端原生客户端（GUILD DECK / 公会掌机）
> 技术栈：**Tauri 2 mobile**（iOS + Android），复用 `web/` Vue 前端，瘦客户端经 HTTPS 直连线上 API
> 范围：**完整对齐 Web**（全部模块）
> 打开方式：浏览器直接打开 `app.html`（建议切到移动视口 / 设备模拟器查看）

## 1. 签名设计 · GUILD DECK（公会掌机）

延续桌面端「终端接驳 / 链路 LED」世界观——**移动端是它的便携版：一台复古手持 RPG 设备**。手机即机身，三个标志元素贯穿全局，避免落入通用移动模板：

| 标志元素 | 说明 | 位置 |
|---|---|---|
| ① **CRT 开机仪式** | 启动时一条水平亮线纵向展开（经典 CRT 上电），扫描线落定后内容淡入，~600ms | `app.html` `.deck__boot` |
| ② **设备状态条 + 链路 LED** | 顶部像素 logo + 与桌面端同源的链路 LED（在线脉冲 / 同步旋转 / 离线熄灭）+ mono 时钟电量 | `.statusbar` / `.link` |
| ③ **方向键式 Tab Dock** | 底部导航做成控制甲板；中央是凸起的像素「公会徽记」FAB，直进 AI 智核 | `.tabbar` / `.crest` |

视觉沿用全局体系：Sweetie-16 冷调深蓝（`--pixel-*` / 此处别名 `--c-*`）、CRT 扫描线 + 暗角、**硬边框无圆角**（`--rad:0`）、全程 `steps()` 阶跃动画。

> **字体（已定）**：跟随现网 `web/` —— **系统字体**（正文/标签）+ 等宽（数据/数字）。复古辨识度由配色/几何/CRT/硬边框/steps() 承担，不依赖像素字体。与现网 `web/src/styles/fonts.css` 完全一致。

## 2. 导航结构

底部 5 槽 Tab Dock + Hub 模式：

```
主城(⌂)   物品(◈)   [✦智核徽记]   委托(⚑)   我的(◉)
                          │
                          └─ 凸起 FAB，直进 AI 对话（NEXA 智核）
```

- **主 tab（5）**：主城 / 物品 / 智核 / 委托 / 我的
- **次级模块**：由「我的」Hub 格进入 —— 世界地图 / 统计 / 冒险日志 / 冒险者履历 / 传输 / 设置
- **首次启动流**：开机接驳（链路信号塔 + 服务器地址）→ 登录/注册 → 角色创建 → 主城
- **新建动作**：列表页右下角上下文 FAB（物品 +、日志 ✎）；委托可召唤 NEXA AI 生成

> 把 AI 智核放在 Dock 正中徽记位，是刻意选择：PixelPack 是 AI 重度应用（AI 情报 / AI 任务 / AI 履历 / AI 对话），让智核成为视觉与交互中心。

## 3. 屏幕清单（16 屏，完整对齐 Web）

| # | 屏 | 路由 | 说明 |
|---|---|---|---|
| 1 | 开机接驳 | `handshake` | 首次链接服务器（信号塔 + 端点输入） |
| 2 | 登录 | `login` | 冒险者凭证 |
| 3 | 注册 | `register` | 新冒险者缔约 |
| 4 | 角色创建 | `character-create` | 选职业 + 命名 |
| 5 | 主城 | `dashboard` | 冒险者卡(等级/经验/连签) + 今日委托进度 + 情报速报 + 快捷行动 |
| 6 | 物品列表 | `items` | 汇总(总资产/总日均/件数) + 状态筛选；**每件展示日均成本·总消耗·使用天数** + 新建 FAB |
| 7 | 物品详情 | `item-detail` | **日均成本(核心)** + 成本拆解(购入/总消耗/天数/残值) + 附加成本明细 + 编辑·改状态 |
| 8 | 物品表单 | `item-form` | 基本信息 / 购买信息 / 使用与折旧 / 附加成本 |

> **物品模块数据口径**（对齐现网 `web/` 与后端 `models/item.py`）：每件物品 = 资产成本追踪。后端已计算 `daily_cost`（每天使用价格）、`total_cost`（总消耗＝购入价＋附加成本）、`per_use_cost`、`usage_days`、`current_value`（残值）等字段；设计稿据此呈现，非 RPG 库存。
| 9 | 委托大厅 | `quests` | 今日/全部/成就 + 完成印章 + AI 生成入口 |
| 10 | 智核对话 | `chat` | NEXA 流式对话 + tool 状态行 + task_created 卡 |
| 11 | 我的 | `profile` | 用户卡 + 模块 Hub + 应用锁/设备会话 + 登出 |
| 12 | 世界地图 | `worldmap` | 信号台 ON AIR + 今日情报 + 航海日志 |
| 13 | 统计 | `stats` | 周经验 + 像素柱状图 + 物品分布 |
| 14 | 冒险日志 | `blog-list` / `blog-detail` | 日志列表 + 详情 |
| 15 | 冒险者履历 | `resume` | A4 衬线简历纸预览 + AI 编辑 + 导出 PDF + 版本/Undo |
| 16 | 传输 | `transfer` | WebRTC P2P + 配对码 |
| — | 设置 | `settings` | 账户 / 应用锁(PIN+生物识别) / 设备会话 / 外观 / 登出 |

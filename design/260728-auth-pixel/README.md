# PixelPack · 登录 / 注册 设计稿（Hi-fi Pixel · 高保真像素）

> 在纯高级版（见 `../260728-auth-ui/`）基础上，融入**像素工艺**——
> 对一个叫 **PixelPack**、主打 RPG 化的产品，这才是"对"的方向。

## 核心理念：像素当"产品数据层"的工艺签名，不当全屏复古滤镜

旧的"AI 味"恰恰来自像素元素**用得太满太廉价**：CRT 扫描线、闪烁星点、`>` 终端梗、满屏像素字、硬偏移投影。
本稿反其道而行——**高级感当底座，像素当点睛**，用一道清晰的分工让两者共存：

| 区域 | 风格 | 含义 |
|---|---|---|
| **像素区**：角色存档卡、经验条、密码强度、等级徽章、统计图标 | 高保真像素（直角、角标、像素块、像素字、像素图标） | 产品的"游戏 / RPG 数据层"——讲 PixelPack 的语言 |
| **控件区**：输入框、按钮、正文、标题 | 现代精致（圆角、玻璃、渐变、Space Grotesk/Inter） | OS 级认证控件——保持可用与高级 |

> 像素只出现在"游戏数据"相关表面，认证控件保持干净。这是可辩护的设计立场，而非把像素糊满全屏。

## 像素工艺清单（成体系、克制）

1. **分段像素经验条**（主签名）—— 登录卡 EXP、注册密码强度都变成一块块亮起的像素格（Balatro/Hades 式）。注册时密码强度实时点亮格子，越强越多。
2. **角标 HUD 取景框** —— 角色卡四角的 L 形青色刻度；卡片改为**直角**，与输入框圆角形成"像素区 vs 控件区"对比。
3. **像素微图标** —— 物品=像素宝石、连胜=像素火、成就=像素星（SVG `<symbol>` + `shape-rendering: crispEdges`）。
4. **"LV" 像素字** —— 仅等级徽章用 Press Start 2P，极小、点睛；正文仍是现代字体。
5. **像素抖动底纹** —— 角色卡上极淡的点阵纹理，致敬像素美术的 dithering 技法。
6. **方形像素 brand-dot** —— 顶栏品牌点改为方块（替代圆点），呼应像素主题。

### 彻底丢弃（这些是旧版"AI 味"的来源）
CRT 扫描线、闪烁星点 / 光标、`>` 终端梗、硬 `3px 3px 0` 偏移投影、Press Start 2P 当正文字体。

## 两个版本对比

| | `../260728-auth-ui/`（纯高级版） | `./`（Hi-fi Pixel · 本稿） |
|---|---|---|
| 品牌契合 | 干净通用 | **强**（像素 = PixelPack 的产品语言） |
| 经验条 | 平滑渐变条 | 分段像素块（点亮式） |
| 角色卡 | 圆角玻璃 | 直角 + 角标 + 像素底纹 |
| 统计 | 纯数字 | 像素图标 + 数字 |
| 适用 | 想要最克制的现代感 | 想要"高级 + 有 PixelPack 灵魂" |

## 调节像素浓度

像素浓度可平滑增减，不需要推翻设计：
- **更克制**：去掉角标 / 抖动底纹，经验条改回平滑条，只保留像素图标。
- **更浓**：给输入框聚焦态加像素角标、主按钮加切角（clip-path）、标题加像素装饰。
- 关键变量：`.blocks` 的 `data-blocks`（格子数）、`.px-ico` 尺寸、`--f-pixel` 的使用范围。

## 落地到 Vue

与纯高级版映射一致（见 `../260728-auth-ui/README.md`），额外点：
- 像素图标 sprite → 放进 `web/src/components` 或 `public`，用 `<svg><use>` 复用。
- `buildBlocks()` / `fillBlocks()` → 移植为组合式函数，数据驱动 `--exp` 与 `.on`。
- 字体：`fonts.css` 增加 Press Start 2P（**仅用于 LV 徽章等点睛**，勿用于正文）。
